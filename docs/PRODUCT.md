# 日知：让坚持有入口，让积累有去处

## 真正想达成的结果

每天更有意识地生活，更有根据地理解社会，在人工智能与计算机领域形成自己的专业判断。衡量成长的核心是能否讲清一个问题、提出根据、承认边界，并在新证据出现后修正判断。

## 一天怎么过

### 忙碌日：2 分钟

「轻量记录」只留一句经历。保持与自己的连接，累计天数照常增加。没有补签惩罚，没有把累计成果清零的机制。今天写得短，不影响明天写得深。

### 普通日：约 15 分钟

1. **留住今天，约 3 分钟。** 具体经历 → 当下感受 → 带走的一句话。每天一篇，可以补记过去、继续编辑。
2. **认识一点世界，约 5 分钟。** 选一个问题或一条新闻，读原文、附链接、写摘要。一天只挑一件就足够。
3. **长出一个想法，约 5 分钟。** 用自己的话解释原因，区分事实、推测和观点，指出证据与边界。完成状态由实际保存的内容计算。

每日三步是温和的路径建议，不是必须完成的考核。每周默认目标是记录 4 天，可以调整到 2—7 天。成长统计按真实有记录的日期去重。

## 信息如何变成知识

卡片结构：标题、领域、类型、日期、来源链接、摘要、事实与证据、自己的解释、边界与反例、规律与连接、继续追问、标签、消化阶段、回想日期。

- **待消化：** 先收进来，避免捕捉灵感时被长表单阻断。
- **在思考：** 已有问题或初步理解，进入回想计划。
- **能讲清：** 需要有自己的解释、有证据、有适用边界；状态是自我评估，系统不自动判定内容正确。

规律作为可检验的假设保存，不鼓励凭单个新闻得出普遍结论。后续证据可以直接修改原卡片，并在周复盘中记录观点变化。

## 怎样理解社会事件

分析一件事时，先厘清发生了什么与哪些尚待核实；再看参与者、各自激励、信息差、成本由谁承担，以及正式规则和实际约束。最后提出其他可能解释，写明什么证据会改变自己的判断。

资讯页保持来源、原始日期和抓取时间可见。来源不等于事实；新闻只是练习理解的入口。政策、数据等尽量回到政府原文、统计机构、论文等一手资料。系统不自动生成结论。

## 广度与深度怎样并行

长期主修：人工智能与计算机。五阶段建议路线：

1. 建立地图：计算、数据、算法、机器学习与大模型的关系。
2. 打好地基：数据划分、训练、优化、泛化与过拟合。
3. 理解核心：注意力、Transformer、预训练、微调和推理。
4. 走向系统：检索、评估、推理效率、显存与计算。
5. 形成判断：研究证据、基准局限、产业成本和社会影响。

每阶段提供问题和笔记入口，不以打勾冒充掌握。用「实践课题」写清小成果与完成标准，自己标记是否完成。主修笔记按领域归集，可在设置中调整主修；其他主修方向使用通用的五阶段研究路径。

广度探索：社会公共事务、经济商业、历史文化、科学技术、心理生活，按星期轮换提示。周末重复部分方向只是提示，不构成必须完成的安排。知识版图呈现分布，不要求所有领域分数相同。

## 记住与表达

回想间隔：1、3、7、14、30、90 天。先不看原笔记，试着解释，再展开答案自评。记得则延长间隔；说不清则次日再见。该计划是产品的回顾安排，不代表对个体记忆效果的保证。

每周复盘留五部分：原来的判断、新的证据、现在的解释、边界和反例、下周的一个问题。建议写 200—500 字，不设置字数考核。逐步形成可以拿来交流的专题解释。

## 成就感从哪里来

- 累计真实记录天数，重复编辑同一天不增加天数。
- 卡片总数和能讲清的知识点，展示从收集到理解的变化。
- 近 26 周热力图，把手记、知识与复盘放进同一时间轴。
- 周目标、知识版图、实践成果和里程碑，共同呈现深度与广度。
- 连续天数只作描述，断一天不影响累计成就。

演示空间的内容明确标为示例；创建自己的空间后从零开始，不把示例算进个人成绩。

## 写作与保存的细节

- 日记、卡片、复盘的正文使用 Markdown 原文存储；编辑、对照与预览切换不改写源文本。
- 写作采用独立全页路由：宽幅正文为主，分类、阶段、来源等放到信息侧栏；顶部固定保存、全文预览、导出和返回。手机侧栏移到正文下方。刷新地址后登录可继续恢复草稿；浏览器前进与后退同样保留写作路径。
- 草稿以原有记录 ID 或新建入口区分，轻量手记和完整手记分别保留草稿。自动草稿在停顿后加密存储，关闭编辑也会保存；再次打开需主动恢复，避免静默覆盖正式记录。
- 正式保存校验必要字段，保存成功才关闭表单；存储失败时保留页面内容并提示导出。
- 轻量手记只修改经历与心情，保留此前的感想和收获；同一天的重复日记要求回到原记录继续编辑。
- 单篇 Markdown 文件以「原记录日期_记录类型_标题_导出-北京时间」命名；全量存档以导出日期和昵称命名。文件名自动清洗非法字符、保留名、控制字符和末尾点，防止 Windows 保存异常；长标题截短，毫秒时间降低重名概率，最终由浏览器处理同名文件。
- 单篇导出含元信息、原始 Markdown、来源、证据和边界。全量 Markdown 包含全部正式日记、卡片、周复盘和实践课题；加密备份还包含个人设置、回想进度和草稿，可完整恢复。
- 换设备恢复前验证密码与备份结构；已存在本地空间时需明确确认替换。解析或密码验证失败不会改写本地数据。
- 同一浏览器的其他标签页修改记录后，当前页停止写入，仍可导出当前页备份；重新登录读取最新数据。

当前没有：服务器账号注册、邮箱找回密码、后台自动多端同步、AI 内容评判、推送提醒。界面如实说明这些边界。这样第一天就能使用，后续可以在不改变卡片结构的前提下接入真正的云端账户服务。
